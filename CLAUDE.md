    38+### Backend (`services/api/`)
    39+
    40+Go-based API using Chi router, PostgreSQL with pgx driver, sqlc for type-safe SQL, and Goose for migrations.
    42+
    43+### Architecture
    44+
    45+```
services/api/
    46+├── main.go              # Entry point, router setup, DB connection
    47+├── internal/
    48+│   ├── db/              # Generated by sqlc - DO NOT EDIT manually
    49+│   ├── handler/         # HTTP handlers (request parsing, response formatting)
    50+│   └── service/         # Business logic layer
    51+├── migrations/          # Goose SQL migrations
    52+├── queries/             # SQL queries with sqlc annotations
    53+└── .env.example         # Environment template
    54+```
    55+**Layer flow**: Handler → Service → db (generated)
    56+
    57+### Key Patterns
    58+
    59+- **sqlc**: Write SQL queries in `internal/db/queries/` with `-- name:` annotations, then run `make generate-db` to generate type-safe Go code in `internal/db/generated/`
    60+- **UUIDs**: Uses UUID v7 for primary keys
    61+- **Soft deletes**: Use `is_active` boolean flags instead of hard deletes
    62+- **Currency**: Default currency is MXN (Mexican Pesos), stored as `NUMERIC(19,4)`
    63+
    64+### Database Schema

    66+Entities: accounts, categories, transactions, debts, debt_payments, investments, subscriptions, subscription_payments
